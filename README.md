# Dhanush Kumar J R: portfolio

This is the code behind my personal site: **https://dhanushdk.github.io**

I'm a Business Analytics master's student at the University of Oulu in Finland. Before that I spent a year building finance and freight software, so I like data work that is careful, readable and useful to someone. The site is a small place to show what I've built and how to reach me.

## What's on it

- A short intro, and a chart you can drag across to see cheap and expensive hours of electricity (the shape is an illustration, not real data)
- My projects: customer data quality, Oulu's late snow, household electricity prices, and a few machine learning experiments. Tap a project to see the details, or open its repository on GitHub
- My path so far: studies and jobs
- A toolbox, a resume I can update any time, and ways to get in touch

## How it's built

It's one `index.html` file with plain HTML, CSS and a little JavaScript. There is no framework and nothing to install. I kept it that simple so I can edit it in the browser and have the site update a minute later.

```
index.html          the whole site
images/             my photo
images/icons/       tool icons
images/flags/       language flags
Dhanush_Kumar_CV .pdf   the resume people can download
```

## Updating it

- **New project:** copy one of the project cards in `index.html`, change the text and the link
- **New resume:** upload the PDF over the old one, or put new PDFs in a folder called `resume` and they show up on their own
- **Different icon:** upload a file with the same name into `images/icons`
- **Try it locally:** open `index.html` in a browser. The GitHub list only appears once the site is live

## Notes

The small tool icons are simple drawings, not official logos. They are plain SVG files, so any of them can be swapped for another image with the same name.
